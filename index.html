Proyectos Demostrables
Program.cs

var builder = WebApplication.CreateBuilder(args);

// Configuración DbContext & JWT

builder.Services.AddDbContext<AppDbContext>(options =>

options.UseSqlite("Data Source=tickets.db"));


builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme);

builder.Services.AddControllers();


var app = builder.Build();

app.UseAuthentication();

app.UseAuthorization();

app.MapControllers();

app.Run();

Proyecto Destacado

API REST para la gestión de incidencias IT, soporte y usuarios.

.NET 8 SQLite JWT

System Ticket API Backend

API RESTful desarrollada en C# para la administración centralizada de tickets de soporte técnico. Implementa roles de usuario (Admin, Técnico, Usuario), cambio de estados de incidencias y autenticación mediante JWT.

  • Registro e inicio de sesión con hash de contraseña.
  • Endpoints protegidos con atributo [Authorize].
  • Migraciones automatizadas con Entity Framework Core.
